MIDI · Arturia → Harmonic → Ableton

MIDI input and output run in the local version of this page on your Mac. Browsers block MIDI inside shared pages. Everything else here works the same.

First-time setup on Mac (about 2 minutes)
  1. Open Audio MIDI Setup (Spotlight). Menu Window → Show MIDI Studio. Double-click IAC Driver, tick Device is online, Apply.
  2. Reload this page. Output should switch to IAC Driver Bus 1 by itself.
  3. In Ableton: Settings → Link, Tempo & MIDI. Under MIDI Ports, turn on Track for IAC Driver (Bus 1) input.
  4. On your instrument track, set MIDI From to IAC Driver (Bus 1) and Monitor to In. This keeps the Arturia's raw notes out, so you only hear the chords.
  5. Play. Hold a key: chord. Release: silence. Sustain pedal, mod wheel and pitch bend pass straight through.
