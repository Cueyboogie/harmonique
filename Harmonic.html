MIDI

MIDI works in the local app on your Mac (double-click Start Harmonic). Allow MIDI when Chrome asks.

  1. Audio MIDI Setup → Window → Show MIDI Studio → IAC Driver → Device is online.
  2. Ableton → Settings → Link, Tempo & MIDI: IAC Driver input: Track on, Sync on. Set tempo to EXT.
  3. Chord track: MIDI From = IAC Driver (Bus 1), Ch. 1, Monitor = In.
  4. Melody / bass track (KEYS PLAY → NOTES): MIDI From = IAC Driver (Bus 1), Ch. 2. Both tracks can stay armed: each only hears its own channel.
